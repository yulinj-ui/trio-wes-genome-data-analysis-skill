# 疑难隐匿病例扩大挖掘手册

> 当标准严格筛选(罕见 + 高危害 + 遗传模式干净)结果为空,或候选基因很好解释表型但遗传模式不完全相符时,启用本手册。核心是从"变异优先"切换到"**表型优先的反向搜索**"。
>
> 目录:
> 0. 总原则:表型优先反向搜索
> 1. 复合杂合 LP+VUS(AR 第二等位救援)
> 2. 隐性病仅发现单个致病等位(寻找第二打击)
> 3. 外显不全 / 表现度可变
> 4. 女性 X 连锁 + 失活偏移

## 0. 总原则:表型优先的反向搜索

标准流程是"variant-first":先按频率/危害/遗传模式过滤出一小批变异,再看它们落在哪些基因。疑难病例要反过来做"**phenotype-first**":

1. 锁定表型对应的候选基因集合(panel + HPO 关联基因 + 通路相邻基因)。
2. 对这些基因,**放宽甚至取消**过滤,把先证者在这些基因里携带的**所有**变异全部列出(任何后果类型、频率放宽到 popmax ≤ 1-2%、含内含子/UTR/同义)。
3. 逐个人工审视:是否有被严格过滤"误杀"的真候选?尤其是下面第 1-6 类情形。

理由:严格过滤是为了在全外显子上控制假阳性,但它在"已知该基因与表型强相关"的小范围内会误杀真阳性(如把致病的深内含子变异、把与已知致病等位反式的 VUS、把遗传自健康亲代的外显不全变异都滤掉)。在候选基因这个小范围内,召回率比精确率更重要。

## 1. 复合杂合 LP+VUS —— AR 第二等位救援

**场景**:某 AR 疾病基因,患者表型高度匹配,已找到**一个**明确致病(P/LP)等位,但严格 comp-het 筛选没配上第二个,因为第二个等位只是 VUS 被滤掉了。

**做法**:
- 在该基因内,主动寻找与已知致病等位处于**反式(trans,分别来自父母双方)**的第二个变异,**放宽到 VUS 甚至更宽**。
- 第二等位的候选类型要覆盖:错义 VUS、剪接区变异、深内含子变异(用 SpliceAI,内含子区放宽)、影响剪接的同义变异、5'/3'UTR、单/多外显子 CNV(需 CNV 模块)。
- **关键增益**:一旦确认第二等位与已知致病等位**反式**,这本身就是 **PM3 证据**,可把原本的 VUS **上调**(反式 + 已知致病搭档 → PM3;多个独立病例可到 PM3_Strong)。也就是说,LP+VUS 的组合经过相位确认后,VUS 那一侧的分级可能提升,整体复合杂合的致病证据链因此成立。
- 反过来:调用 gene-variant-pathogenicity 判读该 VUS 时,**必须把"与已知 P/LP 等位反式"这一信息作为输入喂进去**,让它据此考虑 PM3。

**注意**:确认相位需要 trio 数据(看变异各自来自父/母)或长读段;若父母其一也携带两个变异,需排除顺式(cis,同一条染色体)。

## 2. 隐性病仅发现单个致病等位 —— 寻找"第二打击"

**场景**:表型高度指向某个 AR 基因,却只找到**一个** P/LP 等位,另一个怎么都找不到。**这是"表型对但 WES 阴性"最常见的原因**,绝不能就此收手判阴性。

**系统排查第二打击**(按性价比排序):
1. **覆盖盲区**:该基因是否有外显子/区域在先证者测序深度不足(查 mosdepth per-base 或 IGV)?捕获不到 = 检测不到,不等于不存在。
2. **深内含子 / 剪接**:标准 WES 只覆盖外显子±少量侧翼。第二打击可能是深内含子致病变异(经典如 ABCA4、CEP290 的深内含子突变),需 SpliceAI 全区间评估,必要时上 WGS 或 RNA。
3. **CNV / 单外显子缺失重复**:WES 对 CNV 灵敏度低。跑本机 CNV 补充扫描(ExomeDepth/CNVkit/手动深度比值),重点看该基因;或结合已送检的 CMA。
4. **UPD(单亲二体)**:一个杂合变异若因 UPD 变成纯合,trio 里会表现为"仅一方亲本携带、子代纯合、另一方对应区域缺失杂合性"。查该染色体的 ROH / 孟德尔错误模式。
5. **调控区 / 启动子 / UTR**:影响表达量的非编码变异。
6. **假基因干扰**:某些基因(如 PKD1、部分 CYP 家族)有高度同源假基因,短读段比对困难,易假阴。

**输出**:明确告诉用户"找到一个致病等位,第二打击疑似落在 WES 盲区[具体哪类]",并给出针对性补充检测建议(该基因 MLPA/靶向 CNV、WGS、RNA-seq、或 trio 甲基化/SNP-array 查 UPD)。

## 3. 外显不全 / 表现度可变

**场景**:一个不错的 AD 候选变异,遗传自一位**临床表型正常**的亲代——标准 de novo 筛选会直接排除它,或分析者会因"父母正常"就否掉。

**做法**:
- **不自动排除**遗传自健康亲代的变异,前提是该基因是有文献记录的外显不全 / 表现度可变基因(相关疾病谱内)。
- 查该基因-疾病对的**外显率**数据(文献 / ClinGen);外显率明显 <100% 时,健康携带亲代与致病性并不矛盾,**不应赋 BS2**(SVI 明确:外显不全疾病不用 BS2)。
- 建议对携带亲代做**针对性检查**(如相应器官超声/影像),排查亚临床表现——常能发现"其实亲代也有轻微受累"。
- 考虑修饰因素 / 二次打击模型(如 TBX6 亚效单倍型 + LOF)。
- 产前尤其注意:胎儿外显率本就不明确,不能用产后外显率直接外推。

## 4. 女性 X 连锁 + 失活偏移(skewed XCI)

**场景**:女性先证者/胎儿,携带一个 X 连锁隐性(XLR)疾病基因的**杂合**致病变异。经典观念"女性杂合是携带者、不发病"在此**可能不成立**。

**关键机制**:女性两条 X 随机失活,若 X 失活**偏向表达野生型 X**则不发病,但若**偏向表达携带致病变异的 X**(skewed XCI),则可发病,严重度可接近男性。某些 XLR 病中偏移携带者可出现完整或部分表型。

**做法**:
- 女性先证者的 XLR 致病/疑似致病变异,**不能仅凭"杂合"就排除**;若表型匹配该 XLR 病,保留为候选。
- 明确告知:**X 失活偏移无法从 WES 数据判断**,需专门的 XCI 检测(如 HUMARA / RNA 等位表达),建议补充。
- 同时考虑 X 连锁的其他模式:
  - **X 连锁显性**(女性可发病)。
  - **男性致死型 XL**(如某些基因,男性半合子胚胎致死,存活者多为女性)——**对女性胎儿尤其相关**,一个"看起来是杂合"的 X 变异可能正是这类病的典型呈现。
- 若为男性先证者,X 变异是半合子,按 XLR 常规处理(半合子致病等同纯合)。

## 5. 亲代生殖腺嵌合(解释"复发但父母血样阴性")

**场景**:复发性表型(如多次妊娠同一异常),先证者查到一个看似 **de novo**(父母外周血 0/0)的致病变异。若真是随机 de novo,复发概率极低,与"多次复发"矛盾。

**机制**:亲代**生殖腺(生殖细胞系)嵌合**——变异只存在于部分生殖细胞,外周血测不到,却可反复传给后代。这解释了"外周血阴性却复发",且**再发风险显著高于普通 de novo**(可达百分之几到更高)。

**做法**:
- 对复发病例中的强 de novo 候选,**检查父母 CRAM 在该位点是否有极低 VAF 的 alt reads**(用 samtools mpileup / IGV 看,标准 caller 会把 <10-15% VAF 当噪音过滤掉,需手动看原始 reads)。
- 即使父母 reads 完全阴性,仍不能排除生殖腺嵌合(生殖腺独立于外周血)——遗传咨询中必须提示这一再发风险。
- 这是本类病例遗传咨询(再次妊娠风险、PGT-M 决策)的**关键点**,务必写进结论。

## 6. 双重诊断 / 混合表型(blended phenotype)

**场景**:某个变异能解释患者**部分**表型,但有一部分表型它解释不了。分析者容易在找到"一个不错的候选"后就停手。

**做法**:
- 当最佳候选**无法解释全部核心表型**时,不要收手——主动寻找第二个独立病因(约 5% 的分子确诊病例是双重诊断)。
- 把"未被解释的表型子集"当作新的 phenotype-first 搜索起点,重跑候选基因搜索。
- 尤其当表型横跨两个明显不同的器官系统 / 通路时(一个基因难以同时解释),优先怀疑双重诊断或染色体/CNV 综合征背景。

---

## 7. 标准 WES 天生漏检的变异类 + 补充检测决策

务必向用户显式声明本流程(短读 WES)对以下类别的覆盖限度,并按需给补充检测建议:

| 变异类别 | WES 覆盖 | 补充手段 |
|---|---|---|
| CNV / 外显子级缺失重复 | 弱 | CMA、本机 CNV 扫描、MLPA、WGS |
| 结构变异 / 平衡易位倒位 | 否 | WGS、核型、光学图谱 |
| 深内含子 / 非经典剪接 | 弱 | SpliceAI 全区间、RNA-seq、WGS |
| 重复扩增(如 FMR1、HTT) | 否 | 专项 PCR / Southern |
| 印记 / UPD | 否 | 甲基化 MS-MLPA、SNP-array |
| 线粒体基因组 | 否(核基因组捕获不含) | 线粒体专项测序 |
| 低比例嵌合 | 弱 | 深度测序、多组织取样 |
| 非编码调控区 | 否 | WGS、功能实验 |

**决策原则**:表型高度提示某机制、但 WES 该机制覆盖弱时,不要用"WES 阴性"下"无遗传学发现"的结论——要指出"WES 对[该机制]覆盖有限,建议[具体补充检测]"。

## 8. 落地操作:放宽过滤的具体做法

在本机流水线上执行 phenotype-first 反向搜索的实操:

1. **不重跑比对/call**,直接在已注释的 trio VCF 上操作(`results/trio.annot.vcf.gz`)。
2. **按 panel 基因取全部变异**(参考会话中已验证的命令模式):
   ```
   SnpSift extractFields ... | awk '$GENE in panel'   # 不加频率/危害过滤
   ```
   或 `bcftools view -r <基因区间>` 直接按坐标取,连内含子一起看。
3. **频率放宽**:popmax 阈值从 0.001 放宽到 0.01-0.02(AR 病携带频率可以不低)。
4. **后果类型放开**:纳入 splice_region / intron / synonymous / UTR,再用 SpliceAI 分数二次筛剪接影响。
5. **相位判断**:用 trio 基因型确定变异来自父/母,判断复合杂合是否反式。
6. **CNV 补充**:用 mosdepth 已有的逐外显子深度做归一化比值扫描(按各样本自身整体深度归一化后再比),或跑 ExomeDepth/CNVkit;重点扫 panel 基因。
7. **低 VAF 复核**:对复发病例的 de novo 候选,`samtools mpileup` 看父母原始 reads。
8. 把扩大挖掘出的每个新候选,同样送 gene-variant-pathogenicity 判读(并把相位/外显不全/XCI 等背景信息作为输入喂进去,让它据此考虑 PM3/PS2/降 BS2 等)。

## 收尾自检

扩大挖掘后,回答这几个问题再收工:
- 患者的**每一个核心表型**是否都有候选解释?若否,是否已考虑双重诊断 / WES 盲区?
- 找到的候选,其基因已知疾病谱是否**真的**覆盖具体表型(诚实,不强关联)?
- 若是复发病例:是否已评估生殖腺嵌合、是否已检查候选在所有相关个体中的一致性、是否避免把"重复传递"误当致病证据?
- 阴性/不确定的部分,是否已给出明确的补充检测方向,而非草率下"无发现"?
